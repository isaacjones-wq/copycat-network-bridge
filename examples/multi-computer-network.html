🖥️ Copy Cat - Multi-Computer Network Demo

How It Works

This example demonstrates peer-to-peer networking between Copy Cat computers using the modem API. Open this page in multiple tabs to create separate computers that can communicate with each other.

Each computer automatically gets a unique ID. Try running the example Lua scripts in each computer to send and receive messages across the network.

Example Lua Code

Send a message to computer 2:

modem = peripheral.find("modem")
modem.transmit(2, "myapp", "Hello from computer 1!")

Receive messages:

modem = peripheral.find("modem")
while true do
  local sender, protocol, message = os.pullEvent("modem_message")
  print("From: " .. sender .. ", Protocol: " .. protocol)
  print("Message: " .. textutils.serialize(message))
end

Broadcast to all computers:

modem = peripheral.find("modem")
modem.broadcast("announce", "Hello everyone!")
